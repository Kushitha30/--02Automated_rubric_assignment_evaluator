- Requirements and functional requirements

## Actors

- Student
- Faculty Evaluator

## Use Cases

- Upload Project Submission
- Configure Rubric
- Evaluate Submission
- Generate Evaluation Score
- Review Evaluation Results

## Purpose

The Automated Rubric Assignment Evaluator is designed to automate assignment evaluation using defined rubrics and provide evaluation results to students and faculty evaluators.
